# Font Previews

These previews were generated with `panda_esl.write` using `dry_run: true` on the 256x128 PANDA ESL canvas. Each image uses the same sample text so fonts can be compared directly.

Optional fonts are available in [optional_fonts](../optional_fonts/). Copy any optional `.ttf` file you want to use into `config/panda_esl/fonts/`, then reference the file name in a payload.
